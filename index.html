Keywords of the Densho Digital Repository
About

Each keyword belongs to a "topic" in the Densho Digital Repository, an oral history collection about Japanese American incarceration during World War II. The topics are produced using a statistical technique (LDA) that identifies words that often occur together.

When you hover on a keyword, other keywords from the same topic light up.

When you select a keyword, only keywords from related topics remain. Topics are related if they repeatedly appear in the same interview chapters.

When you select another topic keyword, you can explore interview segments in which both topics are present.

The goal of this project is to help readers find thematic connections across the Densho Digital Repository.
